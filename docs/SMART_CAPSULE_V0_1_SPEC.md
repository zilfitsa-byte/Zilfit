# Smart Capsule V0.1 — Engineering Specification

**Version:** 0.1
**Date:** 2026-05-27
**Status:** Simulation phase — no hardware fabricated

---

## 1. Purpose

The Smart Capsule is an in‑shoe sensor module that collects plantar pressure,
IMU motion, and temperature data during walking. V0.1 exists as a **software
simulation** that generates realistic synthetic sensor streams for algorithm
development, report generation, and doctor/tester evaluation pipeline testing.

No hardware is fabricated in V0.1. All outputs are synthetic.

---

## 2. Sensor Configuration

| Sensor | Type | Position | Sample Rate | Notes |
|--------|------|----------|-------------|-------|
| P0 | Force-sensitive resistor | Heel center | 50 Hz | 0–100 N range |
| P1 | Force-sensitive resistor | Arch / midfoot | 50 Hz | 0–100 N range |
| P2 | Force-sensitive resistor | Ball (met1 head) | 50 Hz | 0–100 N range |
| P3 | Force-sensitive resistor | Hallux | 50 Hz | 0–100 N range |
| IMU | 6‑axis (accel + gyro) | Midfoot dorsal | 100 Hz | ±16g, ±2000 dps |
| Temp | Thermistor | Midfoot | 1 Hz | -20 to 85 °C |

---

## 3. BLE Data Format (Planned)

```
Service UUID: 0x1800 (placeholder)
Characteristic: 20‑byte packets at 50 Hz

Byte 0:     packet_id (0–255, wraps)
Byte 1–2:   P0_raw (uint16, 0–4095)
Byte 3–4:   P1_raw (uint16)
Byte 5–6:   P2_raw (uint16)
Byte 7–8:   P3_raw (uint16)
Byte 9–10:  accel_x (int16, mg)
Byte 11–12: accel_y (int16, mg)
Byte 13–14: accel_z (int16, mg)
Byte 15–16: gyro_x (int16, 0.01 dps)
Byte 17–18: gyro_y (int16)
Byte 19:    temp_raw (uint8, offset -20 °C)
```

## 6. Report Generator Outputs

For a single session, `smart_capsule_report.py` computes:

| Metric | Method |
|--------|--------|
| `steps_estimate` | Heel pressure peak count |
| `heel_strike_events` | Timestamp list where P0 crosses threshold |
| `toe_off_events` | Timestamp list where P3 crosses threshold |
| `pressure_balance` | Mean P0+P1 / Mean P2+P3 ratio |
| `pronation_signal_estimate` | Mean gyro roll angle during stance |
| `fatigue_signal_estimate` | Gait symmetry drift over session (P0 left vs right asymmetry) |
| `recommendation_for_next_insole_design` | Heuristic based on balance + roll |
| `non_clinical_disclaimer` | Always present |

---

## 7. Recommendation Heuristic (V0.1)

```
IF pressure_balance > 1.5 → "Increase forefoot cushioning"
IF pressure_balance < 0.7 → "Increase heel cushioning"
IF abs(pronation_signal) > 8° → "Increase medial/lateral stability geometry"
IF fatigue_signal > 8.0  → "Adjust arch support density"
ELSE → "Maintain current geometry, continue evaluation"
```
